# VideoGamer Magangué

## Proyecto académico - Tienda gamer

Sitio web promocional de VideoGamer Magangué con una sección independiente para PlayStation 4 y una nueva pestaña/página dedicada a PlayStation 5.

### Secciones
- **PS4:** consola, juegos, video, Marvel's Spider-Man, ofertas y contacto.
- **PS5:** nueva página promocional independiente.
- **Características PS5:** SSD, DualSense, gráficos y audio 3D.
- **Juegos PS5 destacados:** Demon's Souls, Ratchet & Clank: Rift Apart, Returnal y Astro's Playroom.
- **Oferta PS5:** botón de consulta por WhatsApp.
- **Diseño responsive:** adaptado a computador, tablet y celular.
- **Carrito:** interacción básica con JavaScript.
- **Menú móvil:** navegación adaptable mediante JavaScript.
- **CSS:** diseño gamer oscuro con efectos, gradientes y tarjetas.

### Archivos principales
- `index.html` - Página principal y contenido PS4.
- `ps5.html` - Nueva página exclusiva para la promoción de PS5.
- `styles.css` - Estilos generales y estilos de PS5.
- `script.js` - Menú, carrito y mensajes interactivos.
- `assets/` - Recursos multimedia existentes.

> Los nombres de juegos y marcas pertenecen a sus respectivos propietarios. Los precios y la disponibilidad deben confirmarse directamente con la tienda.
